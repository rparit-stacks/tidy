Welcome to Tidy

Find what is really using your disk, including the files Finder hides. Two quick things first.

Full Disk Access Required

Lets Tidy read folders macOS protects, like app data and hidden files. It only reads. Nothing is deleted without your confirmation.

  1. Open System Settings below
  2. Turn on Tidy (not listed? click + and pick it, or drag it in from Finder)

Claude Code Optional

Only needed for Smart scan, where Claude explains what each large item is and whether it can go. Uses your own Claude login, no API key. Everything else works without it.

curl -fsSL https://claude.ai/install.sh | bash

Run it in Terminal, then run claude once and sign in.
